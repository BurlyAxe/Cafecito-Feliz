# Cafecito Feliz

Proyecto fullstack con backend en Node/Express y frontend en React.

## Estructura

- `backend/` — API en Express 5 con Mongoose y CORS.
- `frontend/` — Aplicación React 19 con Vite.

## Requisitos

- Node.js 22+
- npm 10+

## Puesta en marcha

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm start
```
